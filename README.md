# ExcelKiller

> **此工具是帮助哥们简化政府工作内容写的工具。**

用一句话说：把一堆格式各不相同的 Excel 表格，按“身份证/某个键”自动对起来补全、或者把各村台账汇总成一张县级总表，省掉人工一列列复制粘贴的活。

---

## 解决的痛点

真实工作里的表格通常长这样：

- 表头不在第 1 行（上面还有大标题、填报单位）
- 两行、三行合并表头（`调整前脱贫户` + `户 / 人`）
- 同一列不同表叫不同名字（`公民身份号码` / `身份证号` / `身份证证件号码`）
- 姓名里带空格（`姓  名`）、日期两种格式混用
- 一户多人只填一次户主信息，其余行留空
- 镇名村名不统一（`万和` / `万和镇`、`曹门` / `曹门村` / `万家湾村村`）
- 表格被筛选过、底部还有上百行预格式化的空白行
- 源表“身份证列”和内容列错行（筛选后粘贴可见单元格的经典事故）

程序对这些都做了自动识别或给出明确的校验提示，尽量不用懂 Excel 公式也能上手。

## 两个功能页

### ① 信息补全

按匹配键（身份证/姓名+手机/自定义多列）把源表的字段填进目标表。

- 目标表工作表可**多选**，自动与源表工作表按名字对应（可手动改）
- 匹配键**自动识别**（身份证 → 姓名+手机 → 手机 → 姓名 → 同名唯一列）
- 字段映射**自动匹配**（含同义列名），可逐个改成 默认/仅填空/覆盖/跳过
- 写入方式：仅填空 / 覆盖 / 仅新增 / 填空并新增 / 覆盖并新增
- **防错行**：键对上但姓名对不上时不写入，并在明细清单单独列出
- **源表冲突**：多源表给同一格不同值时弹窗让你选，选择可记住，也能一键清除记忆
- 只处理可见行开关（表格被筛选时）
- 先预演、后执行；默认另存新文件，原文件不动

### ② 台账合并

把几十个村的“动态调整表”台账（自然变更 / 监测对象新识别 / 消除风险户 / 风险再标注）
逐行汇总进县级同名工作表。

- 源表支持**多选文件**，内部按工作表名自动对上（`5.风险再标注` 与 `风险再标注` 也能识别）
- 源工作表清单默认全选，可按住 Ctrl 自选；且**跟随目标表勾选联动**
- 空白继承上一行（同户多人）、镇/村名自动统一、序号自动重排
- 跳过模板底部预格式化空行，从表头下第一行开始写
- 输出同时生成“合并明细”，记录每个表实际追加了哪些行

## 运行

需要 Python 3.9+ 和 `openpyxl`，界面用标准库 `tkinter`。

```bash
pip install openpyxl
python excel_tool.py
```

打包成免安装 exe（PyInstaller）：

```bash
python -m PyInstaller --noconfirm --onedir --windowed --name "ExcelKiller" ^
  --exclude-module numpy --exclude-module pandas --exclude-module matplotlib ^
  --exclude-module PIL --exclude-module scipy --exclude-module IPython ^
  excel_tool.py
```

> 用 `--onedir` 而不是 `--onefile`：单文件版会往临时目录释放文件，容易被安全软件拦。

## 目录说明

| 文件 | 说明 |
|---|---|
| `excel_tool.py` | 主程序（引擎 + 界面，单文件） |
| `make_rule.py` | 生成示例规则 json |
| `使用说明.txt` | 给使用者看的操作说明与常见问题 |
| `smoke_test.py` 等 `test_*.py` | 开发期测试脚本（需自备样例表格，按脚本内路径调整） |

## 说明

- 程序不联网、不写系统目录、不改注册表；配置只写同目录下的 `设置.json`（字体大小、上次打开的文件夹）。
- 首次运行若提示“Internet 安全设置阻止打开…”，那是文件来自网络的标记，不是病毒：右键压缩包 → 属性 → 勾“解除锁定”，或把程序加入安全软件信任区。
- 写入失败多半是安全软件（火绒/电脑管家等）的“文档保护/勒索防护”拦了 exe，把程序加信任即可。
