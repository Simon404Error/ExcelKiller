Excel填补助手 for睿 v0.1.4  ——  使用说明
==========================================
零之一、启动时会检查管理员权限
  程序启动后会检测当前是否为管理员身份；不是的话弹窗提示
  「建议以管理员身份运行」，可直接点“是”让系统弹 UAC 重新以管理员启动
  （或取消后，右键 exe / 启动源码.bat → 以管理员身份运行）。
  原因：写入 C 盘、系统受保护目录、或某些安全软件限制的文件夹时，
  非管理员容易出现“无法写入 / 拒绝访问”。

零、第一次使用：如果弹出
  “Windows 安全中心：你的 Internet 安全设置阻止打开一个或多个文件 / 打开这些文件可能会对你的计算机有害”
  ★ 这不是病毒提示。原因：压缩包是从微信/QQ/浏览器下载的，Windows 给文件打了“来自网络”标记，
    系统默认阻止运行带此标记的 exe。三种解决办法任选其一：
  办法 A（最省事，推荐）：先解压，再双击文件夹里的「一键解除锁定.bat」，
                          看到“✔ 已解除锁定”后，双击 Excel填补助手.exe。
  办法 B（最彻底）：解压前，右键压缩包 → 属性 → 勾选“解除锁定”→ 确定 → 再解压
                    （解压出来的文件不再带锁，以后都不用管）
  办法 C（换传递方式）：用 U 盘 / 局域网共享拷贝，不会带这个标记。
  本程序不联网、不写系统目录、不改注册表；配置文件只有同目录下的“设置.json”（字体大小）。
顶部工具条：字体大小
  直接改数字或点 ▲▼，界面字号立刻变（无需确认键）；“恢复默认”回到 10。
  设置自动记到程序目录的“设置.json”，下次打开保持你调的号。
一、启动
  ★ 打开“选择文件/保存文件”窗口时会记住上一次所在文件夹（记在程序目录的
    设置.json 里）；第一次选完目标表后，源表对话框会默认打开同一文件夹。
  双击：Excel填补助手.exe（整个文件夹要一起拷走，不能只拷 exe）
  源码方式：双击 启动源码.bat（推荐；它会自动请求管理员权限后启动，
            再自己找 pyw/py/pythonw/python，
            并跳过 Windows 应用商店的占位程序；找不到 Python 会提示）
            另有 启动(需Python).bat，作用相同
二、补信息（最常用）五步
  1) 目标表：选文件 → 工作表列表默认“全选”，可点“全选/反选/清除”调整
  2) 源表：
     · “添加文件…”可多选文件（Ctrl/Shift）：逐文件弹窗询问工作表/表头
     · “添加该文件全部工作表”可多选文件，一次导入所有文件的所有工作表
     · 源表列表支持多选：Ctrl 点选 / Shift 连选，可一次“移除选中”，
       也可一次“调整表头”（把同一套表头设置套到多个源表上）
     · 导入后自动做“结构检查”：同名工作表的列数/列名不一致会逐条告警，
       提示哪个文件多了/少了哪些列（防止漏写或错位）
     · 加完会自动生成“源表工作表 ↔ 目标表工作表”对应关系（同名自动配对）
     · ★ 关于“表格被筛选过”：默认**读取全部行**（含被筛选隐藏的行，程序不受隐藏影响）；
       若只想处理你当前看到的那几行，勾选「只处理可见行（表格被筛选时，忽略隐藏的行）」，
       勾选后会自动按新口径重新读取所有源表。导入时若发现有隐藏行，日志会报告行数。
       注意：如果表格是“筛选后只把可见行复制到新文件”的，那些被筛掉的行在新文件里
       本来就不存在，任何工具都读不回来 —— 请用原始导出文件。
  3) 匹配键：点“自动匹配键”即可 —— 程序按 身份证 → 姓名+手机 → 手机 → 姓名
     → 村+姓名 → 同名唯一列 的顺序自动选，并提示该键在目标表的唯一率；
     也可用左右下拉框手动“添加键”
     ★ 键按“列名”保存，各工作表列顺序不同也能自动定位
     ★ 末位 x/X 不同 → 勾“忽略大小写”；有空格/连字符 → 勾“忽略空格”“忽略符号”
  4) 字段映射：“自动匹配”先配对，再人工核对；缺的用下拉框手动加
     双击某行可在 默认 / 仅填空 / 覆盖 / 跳过 之间切换
  5) 写入方式：新手选“仅填空”；要追加新记录选“填空并新增”
     先“① 预演”看统计 → 确认后“② 执行并保存”
     ★ 点“执行并保存”会弹出保存对话框，由你指定输出到哪个文件夹/文件名；
       默认文件名已填好（带时间戳）。若所选位置写不进去（文件夹只读、被安全软件拦、
       或文件正被 Excel 打开），程序会明确提示并让你重新选，不会直接报错退出。
     ★ 若把保存位置选成“目标文件本身”，会二次确认：确定则直接改写（自动 .bak 备份）。
     关掉“保留原文件”只是把默认保存位置改成目标文件，最终仍以保存对话框为准。
三、表头识别
  表头行默认“自动”，逐表识别：大标题行会自动跳过、两行合并表头会自动合并，
  列名写在上方标题行里（如“核实情况”在第1行、其余列名在第2行）也能自动拼上。
  识别不对时手动填“表头行 / 表头行数”，再点“重新识别”。
四、写入方式（共 5 种，按需选一种）
  · 仅填空 —— 只补空单元格（按人补信息用这个，最安全）
  · 覆盖 —— 用源表值覆盖目标表
  · 仅新增 —— 目标表没有的记录追加到末尾
  · 填空并新增 / 覆盖并新增
  · ★ 防错行开关：“身份/键相同但姓名对不上时不写入”（默认勾选）
    键对上了、但源表和目标表的姓名不一致 → 说明源表“身份证列错行”了
    （常见于：筛选后只粘贴可见单元格、整列上移/下移、剪切粘贴错位）。
    勾选时：这些行不写入，并在日志/明细清单“同键异名（疑似错行）”页列出；
    取消勾选则照常写入（会写错人），一般不要取消。
四之二、台账合并（第二个页签，专用于“多村动态调整表 → 县级动态调整表”）
  场景：手里有一堆 村xxx2026年10月份动态调整表.xlsx，要把它们的台账汇总到
        随县2026年10月份动态调整表.xlsx（县级表）。
  步骤：
    1) 目标表：选县级那份（如 随县2026年10月份动态调整表.xlsx）；
       下面的工作表列表会自动选中 2.自然变更 / 3.监测对象新识别 / 4.消除风险户 /
       5.风险再标注 —— **1.汇总表 不参与合并**（它是按乡镇的统计数字，不能按行合并）
    2) 源表：“添加文件（可多选）…”一次选全部村的动态调整表；
       下面会列出每个文件的**每个工作表**（如“曹门村…xlsx / 2.自然变更”），
       **默认全选**；按住 Ctrl 点一下可取消不想合并的那几个，也可用“全选/全不选”。
       源工作表的选中状态会跟随“要合并到哪些工作表”：在目标表里取消某个表
       （例如 1.汇总表），源表里对应的那些工作表会自动取消选中。
       程序按工作表名自动对上（“5.风险再标注”与“风险再标注”也能识别）
    3) 选项：
       ☑ 空白继承上一行 —— 处理“同户多人只填一次户主信息”
       ☑ 自动统一镇/村名称 —— 万和→万和镇、曹门→曹门村
       ☑ 自动重排序号（从 1 开始连续编号）—— 追加后整列序号重编 1..N，避免出现 63、1、2、3 这种乱号
       ☑ 照搬源表行宽高 —— 新行沿用源表的行高，不会沿用模板里特别高/特别矮的行高
       ☑ 保留原文件 —— 默认另存为 xxx_合并结果_时间.xlsx
    4) 先“① 预演”看每个表将追加多少行，再“② 执行并保存”
       ★ 执行时会弹出保存对话框让你指定输出位置；位置不可用（只读/被占用/被安全
         软件拦截）会提示并让你重选。选定后同时生成“_合并明细.xlsx”。
  注意：合并只做“逐行追加”，不会去重，也不会重算 1.汇总表 —— 重复点两次会重复追加。
  注意：如果“输出文件”正被 Excel 打开（或文件只读），程序会自动改写到
        “xxx(2).xlsx”并提示实际路径；想用原文件名请先关掉 Excel。
五、两个数据预处理开关（合并类必看）
  1) ☑ 源表空白继承上一行（同户多人）
     “一户多人只填一次户主信息”的台账，合并后第二人会成为孤儿行。
     勾上后自动识别“同户共享列”（每户内取值一致且存在空白的列），
     把 镇/村/户主姓名/户主证件/致贫原因 等继承下来；
     点“继承列…”可看到 ★ 自动推断的列，也能自己勾。
  2) ☑ 按规则标准化字段值（如 万和→万和镇）
     点“替换规则…”：
       · 自动统一后缀 —— 把 万和 / 万和镇 统一成 万和镇（跨全部源表比对）
       · 补齐缺失后缀 —— 把 曹门 补成 曹门村、万家湾村村 修成 万家湾村（按列名 村/镇 判断）
       · 也可手动加规则（“列”留空表示对所有列生效）
     目的：避免“万和”与“万和镇”被统计成两个镇。
六、源表内容冲突（多源表时）
  多个源表给同一条记录的同一个字段填了不同的值时，程序会弹窗：
  「源表内容冲突 —— 请选择采用哪个源表的数据」
    · 每条冲突列出候选：① 源表A：值   ② 源表B：值 ……
    · 双击某个候选，或选中后点“采用选中候选”，即可批量设置多行
    · 也可以“全部用第1个源表 / 全部用最后一个源表”一键处理
    · 直接“确定”＝每处默认采用候选①
  你的选择会写进明细清单的“源表冲突（已选）”页，同类冲突本次会记住，
  下次不再问（想重新问 → 点「删除冲突记忆」）。
  ★ 删除冲突记忆：在“写入方式与输出”框右下角。点了会列出当前记住的
    冲突选择，确认后清空，之后同样的冲突会重新弹窗让你确认。
七、规则复用
  “保存规则”存 .json（含工作表对应关系），“加载规则”一键还原。
  自带 示例规则_村表补总表_全工作表.json：村级预警数据 9 个工作表 →
  县级 3315 条预警数据 9 个工作表，只填空、按身份证匹配，可直接加载演示。
八、常见问题
  Q 明明有这人却“未匹配”？→ 格式差异（空格/全角/x-X/前导0），勾清洗项；
    仍不行就看预演页的“目标表未匹配 / 源表未匹配”清单，核对两边实际值。
  Q 会不会破坏格式/合并单元格/公式？→ 只改数据单元格的值，样式与合并区保留；
    新增行复制上一行样式。
  Q 界面模糊或太大？→ 已做高分屏适配；也可用顶部“字体大小”调。
九之一、表尾的“村委会意见 / 填表说明 / 签字盖章 / 填表人”行
  ★ 这是可关的开关（默认勾选）：
    · 信息补全页：源表区的「自动剔除表尾的“意见/说明/签字/填表人”行」
    · 台账合并页：合并选项里的同名开关
    取消勾选后会立即按新设置重新读取（台账页为下次预演生效）。
    如果表内正文本身也带这些字样，担心被误判，取消勾选即可。
  这类行不是数据，勾选时程序会自动识别并剔除（原表不动，只是不参与补全/合并）：
    · 一行里只有 1~4 个单元格有内容，且出现“意见 / 说明 / 签字 / 盖章 /
      负责人 / 填表 / 审核 / 合计”等字样，或有大段长文本 → 判定为表尾行；
    · 只裁掉“连续在表格最末尾”的那几行，正文中间的行不受影响。
  另外：合并/新增数据时，若目标表下方本来就有这种表尾块，程序会把表尾
  整体下移（连合并单元格、行高一起），让新数据紧接正文，
  不会出现“数据跑到签字栏下面”或“签字栏被覆盖”。

九、大表 / “整表格式化”的工作表（很常见）
  有些表被人整列整行刷过格式，Excel 里明明只有十几行数据，但文件记录的表格尺寸
  是 1048576 行。这种表逐个单元格读取会像“卡死”。程序已做处理：
    · 只读到“真实有数据的最后一行”，并忽略离群的零星单元格；
    · 表头合并单元格的填充只在表头区域做；
    · 数据行改为批量读取。
  导入时如果遇到这种表，日志会提示：
    “ℹ 有 N 个工作表被“整表格式化”过（Excel 报表尺寸到 104 万行），已按真实数据读取…”
  实测：11 个村表（22 个工作表）导入约 0.8 秒。

十、写入失败 / 权限问题排查（重要）
  症状：点“执行并保存”弹出“写入失败（文件被占用）/ 无法写入 xxx”，但自己既没打开
        Excel，也没把文件设成只读。
  已排查过的事实：文件夹可正常写入、文件未被占用、无只读属性，但 exe 就是写不进去。
  ★ 这种情况基本是安全软件（最常见是火绒，其次电脑管家/360）的“文档保护/勒索防护”
    拦截了本程序写入 .xlsx。
  解决办法（任选）：
   1) 火绒 → 右上角“菜单”→“信任区”→ 添加文件 → 选中 Excel填补助手.exe；
      或 火绒 →“防护中心”→ 系统防护 → 文件实时监控 → 添加排除该程序/该文件夹；
   2) 临时退出火绒（右下角托盘 → 退出），再点“执行并保存”，能成功即确认是它拦的；
   3) 把“输出文件”改到别的目录（例如桌面）试试 —— 新版遇到目录写不进去时会
      自动询问是否改存到桌面，并说明原因。
  注意：用“源码\启动(需Python).bat”运行时往往不被拦（python.exe 常已被信任），
    所以“源码能写、exe 不能写”基本可判定为安全软件拦 exe。
